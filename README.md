# HyperDuo

把状态栏里的 **Wi-Fi、移动信号、电量** 合并成一个仿 iPhone「Duo」风格的三合一图标。

<img src="https://cdn.jsdelivr.net/gh/yixing233/HyperDuo@main/docs/images/statusbar.png" width="900" alt="HyperDuo 在真实状态栏里的效果">

> **包名已更换**：从 1.4 起是 `io.github.yixing233.hyperduo`（1.3 及更早是 `com.hyperduo.trio`）。
> 包名变了就是另一个应用，**无法覆盖升级**：请先卸载旧版（设置会一起清掉），再安装新版。

HyperDuo 是一个 LSPosed 模块，只作用于系统界面（`com.android.systemui`）。开启后，状态栏右上角
原本分开的 Wi-Fi 图标、信号格与电池图标会被替换成一个整体字形：

- 外圈是**电池环**，缺口在下方，按电量点亮；
- 环里是 **Wi-Fi 弧线**，弧数跟随真实信号强度；
- 底部是**移动信号点**，四个点表示移动网络信号强度；
- 环内是**电量数字**，充电时变成闪电（快充为琥珀色闪电）。

所有元素都能单独开关，尺寸、颜色也可以按自己的状态栏习惯微调，改完**立即生效**，无需重启。

关掉其中任何一项，对应的**系统原生图标**都会回到状态栏原本的位置——关掉「显示 Wi-Fi 弧」，
原生 Wi-Fi 图标回到系统默认位置；关掉「显示移动信号点」，原生信号格回来；关掉「充电时显示
闪电」，充电时就由系统原生的闪电显示在电池图标旁。也就是说每个开关都是「用三合一的画法」与
「用系统原本的画法」之间的切换，而不是简单地少画一笔。

如果更喜欢把电量数字放大到环心、让 Wi-Fi 弧缩到顶部缺口，打开「**电量数字居中**」即可。
开启后数字始终优先占据圆心：充电时改用**顶部缺口里的小闪电**（此时不再画 Wi-Fi 弧，充电状态
一眼可见），环内的网络类型也会让位到缺口。

也可以在「**三合一样式**」里把排布换成**矩形**：左右两列信号点夹住中间的内容，顶部是 Wi-Fi 弧
（或网络类型，充电时是闪电），中部偏下是放大的电量数字，底部是一条横贯左右的电量条。矩形样式
沿用同一套字体、颜色与尺寸设置，只是「环线粗细」这一行会改叫「**电量条粗细**」。

双卡手机还可以打开「**双卡信号**」：在**没有 Wi-Fi 且未充电**时，改成上下两排信号点，**上排是
卡一、下排是卡二**。单卡手机、只有一张卡能读到电平时，或者正在充电时，仍然只画一排——那一排
始终表示**当前上网卡**。信号电平与系统状态栏取同一个来源（MIUI 的 `getMiuiLevel()`），所以双排
不会出现「系统满格、这里少一格」。

信号不一定要画在环里。把「**信号位置**」从**环内**改成**环外**，移动信号就从圆环底部挪到电池
图标旁边。此时打开「**堆叠信号**」，模块自己接管那一处读数：**四条高度递增的圆头柱**表示一张卡，
**下方一排圆点**表示另一张卡；只有一张卡时只画柱。关闭「堆叠信号」则把移动信号整体**交还系统**，
由原生信号格显示——这也是环外模式的默认状态。双卡时还可以再打开「**仅显示上网卡**」，只画当前
承载数据的那张卡，另一张完全不画。

两个开关都**只在环外模式下生效**：环内的点阵、以及上面说的「双卡信号」两排点，都不受它们影响。

## 要求

| 项目 | 要求 |
| --- | --- |
| 系统 | HyperOS / MIUI（已在 HyperOS 4 上完整验证） |
| Android | 10 及以上（API 29+） |
| 框架 | 支持 libxposed **API 102** 的 LSPosed，例如 LSPosed 2.2.0-it（7890） |
| 作用域 | 系统界面（`com.android.systemui`） |

目前只在 **小米 14 · HyperOS 4 · Android 17（API 37）** 上做过完整验证。HyperOS / MIUI 的其他
机型与版本理论可用，但状态栏内部实现不同时，对应功能会自动跳过并写下日志，不会崩溃。

## 设置

设置界面按 **常规 / 尺寸 / 颜色 / 关于** 四个分页组织，顶部是跟着设置实时变化的「效果预览」，
顶栏右侧还有一个**重启系统界面**按钮。

<img src="https://cdn.jsdelivr.net/gh/yixing233/HyperDuo@main/docs/images/settings.png" width="420" alt="设置界面：顶部的效果预览与四个分页">

### 常规

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| 启用三合一图标 | 总开关。关闭后恢复系统原本的电池与信号图标。 | 开 |
| 三合一样式 | **圆环**（默认，元素沿圆环分布）或**矩形**（左右两列信号点夹住中间内容，底部一条电量条）。 | 圆环 |
| 显示 Wi-Fi 弧 | 在最外层绘制 Wi-Fi 弧线，弧数跟随实际信号强度。关闭后原生 Wi-Fi 图标回到状态栏原本的位置。 | 开 |
| 显示移动信号点 | 在底部绘制四个电平点表示移动网络信号强度。关闭后原生移动信号图标回到状态栏原本的位置。 | 开 |
| 双卡信号 | 无 Wi-Fi 且未充电时改画上下两排信号点：上排为卡一、下排为卡二。只在双卡且两卡电平均可读时生效。 | 关 |
| 信号位置 | 两档：**环内**（圆环底部的点）或**环外**（挪到电池图标旁）。 | 环内 |
| 堆叠信号 | 环外时自己画信号：四条递增的柱表示一张卡，下方一排圆点表示另一张卡。关闭则交还系统原生图标。只在环外有效。 | 关 |
| 仅显示上网卡 | 环外堆叠时只画当前承载数据的那张卡。只在环外且「堆叠信号」打开时有效。 | 关 |
| 显示电量数字 | 在环内显示电量百分比；充电时改为闪电图标。 | 开 |
| 充电时显示闪电 | 关闭后不再用环内闪电，改由系统原生的充电闪电显示在电池图标旁。 | 开 |
| 网络类型 | 三档：**关闭** / **环内** / **环外**。 | 关闭 |
| 电量数字居中 | 电量数字放大到圆环中间并始终优先占据圆心。 | 关 |

### 尺寸

| 设置项 | 说明 | 默认 | 范围 |
| --- | --- | --- | --- |
| 环线粗细 | 电池圆环的描边宽度。 | 14 | 4 – 16 |
| 弧线粗细 | Wi-Fi 弧线的描边宽度。 | 12 | 3 – 16 |
| 数字字号 | 电量百分比文字的尺寸。 | 36 | 16 – 44 |
| 数字字重 | 电量数字的笔画粗细，100 最细、900 最粗。 | 700 | 100 – 900 |
| 网络类型字号 | 环内 3G / 4G / 5G 等文字的大小，只影响**环内**模式。 | 32 | 16 – 44 |
| 环外字号 | 环外 3G / 4G / 5G 等文字的大小，只影响**环外**模式。 | 32 | 16 – 64 |
| 网络类型字重 | 网络类型的笔画粗细，环内与环外共用。 | 700 | 100 – 900 |
| 底纹浓度 | 未点亮部分的透明度。 | 56 | 0 – 255 |

### 颜色

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| 状态颜色 | 分别为低电量、充电与危险电量指定颜色。关闭后统一使用状态栏前景色。 | 开 |
| 低电量阈值 | 电量低于该值时切换到低电量颜色。 | 20（可调 5 – 50） |
| 低电量颜色 | 电量处于低电量阈值以内时使用。 | 深色底 `#F2B900` / 浅色底 `#C99700` |
| 充电颜色 | 正在充电时使用。 | 深色底 `#34C759` / 浅色底 `#1F8F3D` |
| 危险电量颜色 | 电量过低时使用，优先级最高。 | `#FF3B30` |

三种状态颜色都可以**分别**为深色背景和浅色背景设置一套。灯环的底纹和未激活的信号点会跟随状态栏
本身的前景色，所以换主题、开深色模式都能自动适配。颜色的优先级是：
**危险电量 → 低电量 / 省电 → 充电 → 前景色**。

### 关于

显示模块版本、系统版本、Xposed 框架、设备型号、作用域与 Android 版本，并提供**检查更新**；更新
卡片底部固定有**查看仓库**。页面底部的**调试日志**开关会把详细过程写入 LSPosed 日志，排查问题时
开启。

检查更新是**手动**触发的：只有点按「检查更新」这一行时才会访问网络，模块不会在后台自动联网。

## 常见问题

**改完设置需要重启系统界面吗？**

不需要。模块通过框架的远程配置通道实时接收变更，改完立刻重绘。如果确实需要重启（例如刚装上
模块、或系统界面状态异常），设置界面顶栏右侧就有重启按钮；它也需要 root 授权。

**状态栏完全没有变化？**

依次确认：模块已在 LSPosed 中启用 → 作用域勾选了「系统界面」→ 已经重启过系统界面。三者都满足后
仍然无效，请检查手机上是否还有别的状态栏类模块在同时改动同一区域。

**「关了 Wi-Fi 弧还在」？**

不会。Wi-Fi 的**有无**有实时采样兜底，关掉 Wi-Fi 后弧线会消失。但 Wi-Fi 的**信号等级**依赖系统
界面内部的资源名解析，个别固件改走别的绑定路径时，弧线可能只显示为不点亮（不会崩溃）。

**切换「显示移动信号点」后没有马上变化？**

移动信号点只在信号等级变化时刷新。这是已知限制：系统界面在移动视图淡出后仍报告「可见」，模块
无法从中判断开关状态，所以需要等下一次信号变化（或重启系统界面）才会完全同步。

**打开「双卡信号」后还是只画一排点？**

第二排需要三个条件同时成立：手机确实是双卡、两张卡都读到了电平、并且当前**没有 Wi-Fi 也没有在
充电**。任何一条不满足就回退成单排（当前上网卡）。

**升级后设置全没了、LSPosed 里还多出一个同名模块？**

包名换了（`com.hyperduo.trio` → `io.github.yixing233.hyperduo`），Android 会当成两个不同的应用：
旧版不会自动升级、旧设置不会迁移、LSPosed 里两条并列。卸载旧的 `com.hyperduo.trio` 与它那条
作用域记录，只留新版即可。

**字号调大后字形被裁切了？**

系统给电池图标预留的区域是固定的（28dp × 20dp），几何参数只改变绘制内容，不会改变预留尺寸。
极端值下字形可能超出可用范围，调小一点即可。
